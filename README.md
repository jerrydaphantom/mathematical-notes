# Mathematical Notes

A collection of mathematical expositions exploring probability, combinatorics, stochastic processes, and asymptotic analysis.

## Articles

### 1. Prisoners and Dickman

**[Read the full article](prisoners-dickman/README.md)**

An exploration of the 100 prisoners problem, beginning with a surprisingly effective strategy based on permutation cycles. We develop the associated combinatorial counting arguments, generalise the problem to arbitrary inspection limits, and derive the Dickman differential-delay equation.

**Topics:** Random permutations · Cycle decomposition · Combinatorics · Harmonic numbers · Asymptotic analysis

**Materials:** Mathematical proofs, diagrams, numerical experiments, and reproducible Python simulations.
